# Product Status

## 1. 当前产品定位

AI Commercial Visual Studio 是一个面向产品设计师、家具设计师、CMF 设计师、电商设计师、品牌设计师和 AI 绘图用户的本地规则型商业视觉方案工作台。

当前版本不接入 AI 接口，不生成真实图片，而是基于本地 JSON 规则，将用户输入的设计对象、项目类型和商业目标转化为可交付的视觉方案包，并输出可直接用于 Midjourney、Flux 和 GPT Image 的 Prompt。

产品方向不是提示词博客，也不是标签拼接器，而是帮助设计师快速生成商业视觉方向、构图策略、CMF 表达、灯光镜头建议和平台专用出图指令的轻量 SaaS 工具。

## 2. 当前核心功能

- 首页输入设计对象，选择项目类型和商业目标，生成商业视觉方案。
- 一次生成 3-6 个差异化视觉方向，例如高端家具展厅、CMF 材质微距、Apple 风官网主视觉、珠宝静物广告等。
- 每个方案卡片展示适合场景、视觉重点、推荐比例、推荐平台、摘要和商业价值。
- 方案详情按视觉方案、视觉执行、使用建议、Prompt 输出分组展示。
- Prompt 输出使用 Tabs，包含中文、English、Midjourney、Flux、GPT Image、Negative、完整方案包。
- 每个 Prompt Tab 支持一键复制，并保留 clipboard fallback。
- 本地保存历史记录、收藏组合和最近使用对象。
- 支持随机灵感和一键随机生成。
- 使用本地 `solution-rules.json` 和 `subject-dictionary.json`，不依赖后端。

## 3. 已解决的问题

- 首页已从标签选择器升级为商业视觉方案工作台。
- 旧标签库不再作为首页主体验。
- Prompt 输出从表单式拼接改为自然语言商业视觉描述。
- 新增主体物中英文词典，解决中文主体物进入英文平台 Prompt 的问题。
- English、Midjourney、Flux Prompt 已避免中文混杂。
- 中文 Prompt 和 GPT Image Prompt 保持中文自然语言表达。
- 新增使用建议和出图迭代建议，提升方案可执行性。
- Prompt 输出已改为 Tabs，减少详情页长度并提升复制效率。
- 修复 React key 重复警告。
- 复制功能已支持 `navigator.clipboard` 和 `document.execCommand("copy")` 降级。
- 已通过 `next build --webpack` 和 `tsc --noEmit` 验证。

## 4. 当前未做的功能

- 未接入 AI 图像生成接口。
- 未做真实登录、账号体系、云端项目保存。
- 未做真实支付或会员权限控制。
- 未做团队协作、项目文件夹、版本管理。
- 未做 Prompt 导出为 PDF、Markdown 或设计提案文档。
- 未做品牌调性预设编辑器。
- 未做图片上传、参考图分析或图生图流程。
- 未做高级参数面板，例如画幅、模型版本、风格强度、seed、批量生成等。
- 未做多语言 UI，只支持中文界面为主。
- 未做完整移动端专项交互优化，只完成响应式适配。

## 5. 下一阶段路线图

### V1.1 质量增强

- 扩充主体物英文词典，但不恢复标签选择器。
- 为不同项目类型补充更精细的商业用途策略。
- 增加方案评分和推荐理由。
- 优化 Negative Prompt 与平台参数规则。

### V1.2 交付增强

- 支持一键导出完整方案包。
- 支持收藏夹分组和历史记录搜索。
- 支持品牌调性预设，例如极简科技、东方轻奢、高端电商、CMF 研究。
- 支持复制为不同格式：纯 Prompt、方案提案、平台参数版。

### V1.3 专业工作流

- 增加项目工作台和方案对比视图。
- 支持批量生成多个商业方向。
- 支持为同一对象生成官网、电商、社媒、作品集等多用途方案。
- 增加平台专用优化规则，例如 Midjourney 参数、Flux 自然语言强化、GPT Image 中文指令强化。

### V2.0 可选 AI 能力

- 在保持本地规则可用的前提下，可选接入 AI 生成或润色。
- 支持参考图上传、风格解析、图片结果管理。
- 支持云端同步和团队协作。

## 6. 当前可演示流程

1. 打开首页。
2. 输入设计对象，例如 `胡桃木休闲椅`、`黑发晶手串`、`便携显示器`。
3. 选择项目类型，例如家具设计、珠宝饰品、官网主视觉。
4. 选择商业目标，例如高级感、材质表达、结构展示。
5. 点击生成视觉方案。
6. 查看 3-6 个商业视觉方向卡片。
7. 点击任意方案查看详情。
8. 阅读视觉方案、视觉执行、使用建议和出图迭代建议。
9. 在 Prompt Tabs 中切换中文、English、Midjourney、Flux、GPT Image、Negative、完整方案包。
10. 点击复制按钮，将对应 Prompt 写入剪贴板。
11. 收藏方案或从历史记录中重新打开方案。
